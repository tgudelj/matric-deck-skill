# MSFS 2020/2024 input configuration

Use the [shared application input workflow](../application-inputs.md) for discovery, inventory, MATRIC mapping and acceptance. This reference covers application-specific formats and limits.

Inspect the chosen account/store's readable profile files. Steam installations commonly use `Steam/userdata/<account>/1250410/remote/inputprofile_*` (2020) or `2537590/remote/inputprofile_*` (2024). Store installations commonly keep readable XML blobs below `%LOCALAPPDATA%/Packages/Microsoft.FlightSimulator_8wekyb3d8bbwe/SystemAppData/wgs` (2020) or `Microsoft.Limitless_8wekyb3d8bbwe/SystemAppData/wgs` (2024). These are discovery hints, not a supported universal export API; use explicit local paths and avoid other account data. Readable XML may contain adjacent `Version`, `FriendlyName`, `Device` elements rather than one root. The reader also accepts wrapped XML and both `Action`/`Actions` entries. Preserve contexts, GUIDs, aircraft metadata, `Flag`, `ValueEvent`, `Delay`, key information and global/local axis curves. Binary/cloud containers, encrypted/unknown formats and automatic active-layer resolution are unsupported; if no readable mapping is available, obtain verified assignments through the game settings. Microsoft's SDK input XML documents device/action structures, but developer defaults are not evidence of a user's active mapping. [Input XML](https://docs.flightsimulator.com/msfs2024/retail/content-configuration/input/input-configuration-xml-properties/), [profile layers](https://flightsimulator.zendesk.com/hc/en-us/articles/16459737949980-Controller-Settings-FAQ), [FSProfiles format and location evidence](https://github.com/iadarroch/FSProfiles).

Confirm general, category and aircraft layers; no precedence is inferred. Numeric keyboard keys translate only when the profile device is explicitly Keyboard. Preserve Flag, timing and axis semantics; device numbers are not Windows key codes.
